# UnityPackage-Converter-for-Godot
Unity2Godot takes a .unitypackage file, such as one bought from the Unity Asset Store, and turns it into assets Godot 4 can use directly.  It unpacks the package and restores the original folder structure. It copies over textures, 3D models, and audio, and converts image formats Godot can’t read (.tif, .psd) to PNG.
